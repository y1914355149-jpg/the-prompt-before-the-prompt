# The Prompt Before the Prompt

> 在让 AI 动手之前，先给自己下一个指令。
> 一个外行的 AI 协作框架。

---

## 这是什么

一个结构化的方法论，帮助普通人（尤其是不懂技术的“小白”）在任何新领域中，用 AI 高效、安全地做事，避免“一改就崩”“拿到手不敢碰”“被术语劝退”等常见翻车。

核心原则只有一句话：**需求不清，不动手做。**

这个 skill 不是你给 AI 下的那个指令，而是**在你给 AI 下指令之前，先给自己下的那个指令**。

---

## 核心流程（6 阶段）
-1. 盲区暴露 → AI 列出该领域最容易踩的 3 个坑
0. 需求冻结 → 5 个问题没填满不动手

领域扫描 → 用 5 分钟建立认知地图

最小实践 → 30 分钟跑通一个最小版本

架构设计 → 规划路径、识别依赖

迭代执行 → 按模块推进，每步验证

复盘归档 → 提取可迁移经验

text

阶段 -1 是这个 skill 最独特的步骤：**在用户提问之前，AI 必须先主动暴露该领域新手最容易踩的坑。** 用户只需回应“都懂了/第几个没概念”，即可进入冻结阶段。

---

## 快速开始

1. 把这个 skill 文件加载给你的 AI
2. 告诉 AI 你要做什么领域的事
3. AI 会先列出该领域最常见的 3 个坑
4. 你回复“都懂了”或“第 X 个没概念”
5. 然后 AI 会引导你完成 5 个问题的需求冻结
6. 冻结之后才开始执行
